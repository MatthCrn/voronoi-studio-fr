# Voronoi Studio — Français

Versions Windows et mises à jour de l’adaptation française de Voronoi Studio, logiciel original de Gilbert Chen.

## Télécharger

Les versions installable et portable sont disponibles dans [Releases](https://github.com/MatthCrn/voronoi-studio-fr/releases/latest).

## Mises à jour Windows

Dans **Application → Mises à jour**, renseigner cette adresse :

https://github.com/MatthCrn/voronoi-studio-fr/releases/latest/download/

La version installée recherche les nouvelles versions et propose de les télécharger, puis de redémarrer pour les installer. La version portable se remplace manuellement. Le logiciel fonctionne hors connexion pour créer et exporter les motifs.
