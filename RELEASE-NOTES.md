# Voronoi Studio FR 1.11.0

- Sélection multiple des panneaux avec Ctrl + clic.
- Groupes de panneaux : grouper, dégrouper, déplacer et verrouiller ensemble.
- Fusion en un panneau lorsque la sélection forme un rectangle compatible.
- Suppression avec emplacement vide, sans déplacer les voisins ; possibilité de recréer un panneau à cet emplacement.
- Motif continu, visibilité indépendante et exports SVG/DXF conservés.

146 tests automatiques réussis.

**Windows 64 bits** : utiliser le fichier installation.exe pour bénéficier du mécanisme de mise à jour. La version portable fonctionne sans installation et se remplace manuellement.

Les anciens projets restent lisibles ; les nouveaux projets avec groupes et emplacements vides demandent la version 1.11 ou ultérieure.

Voir le guide de composition joint pour le fonctionnement détaillé.
